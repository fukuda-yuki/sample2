# Public modernization request

- Source and processing: exact pinned application slice.
- Target and dependencies: what is available without network access.
- Entry points: method, route/input, status and observable output.
- Initial state: seed data, missing database and configuration rules.
- Transitions: sessions, persistence, restart and invalid input behavior.
- Success criteria: every convention the evaluator depends on.
- Allowed alternatives: equivalent markup, ordering, naming and storage choices.
- Exclusions: processing not covered by this task.

Do not include a target implementation, fixture code, private test cases,
credentials, another intervention's instructions or earlier Run results.
