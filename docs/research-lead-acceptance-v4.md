## Reason and retained safeguards

For this study, the scientific prerequisite is a defensible contract and
measurement of ordinary actions and stored results. A human reviewer is not
scientifically indispensable when usability acceptance is not an outcome.
Authority comes from preserved source/data, explicit researcher-authored pricing
rules, raw enum order, independently calculated Decimal expectations, and
observable UI/database results. A modern reference alone is not the oracle.

The five technical prerequisites remain mandatory: evaluation chain, selected
task scope, independent task set, execution evidence and serialized intervention.
The revised gate requires three separately hashed receipts: the actual user
delegation, the named AI lead's decision and a distinct AI worker's methodological
review. The lead and reviewer bind all four variants' normative assets and the
v4 protocol. The decision also references ordinary-workflow and independent
source/oracle evidence. Missing roles, mismatched assets, changed evidence,
unknown policy, or an AI record pretending to be human must block readiness.

Independent AI review means a distinct worker and context. It is neither a
different model nor an external human or independent empirical oracle. Shared
AI mistakes, limited calibration and artificial tasks remain limitations.

The two fixed source families, four nested variants, 64 pairs / 128 slots,
serial concurrency, allocation/order, initial-source intervention, provider,
budgets, evaluation, analysis and missingness rules remain identical to v3.
The new cohort is `runs/source-info-v4`. This administrative acceptance amendment
does not reuse or reinterpret comparative outcomes. The historical 100 pairs and
failed technical evidence remain preserved. No replacement of missing data,
historical rescoring or study dispatch is part of this amendment.

## Freeze and start boundary

The committed source, revised protocol, exact receipts and environment identities
are frozen in a new ledger and bundle. Passing `check` means scientific and
technical preparation is accepted for this v4 plan. It reads no credential and
dispatches no model. Source or evidence changes require another version, not an
edit to the frozen bundle.

An actual separate user start instruction remains required for the exact bundle
hash. No start-approval JSON is fabricated from this delegation. `execute` starts
one pair only after that approval and preflight. The real public verification,
independent download/restore and owned-copy cleanup gate remains required before
the next pair. Uncertain or previously dispatched slots are never replayed.

The [start and recovery guide](research-next-phase-start.md) names the new paths.
Raw private acceptance artifacts stay local; the repository contains the policy,
controller, tests, evidence references and launch instructions.
